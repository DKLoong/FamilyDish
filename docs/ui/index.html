家庭点菜小程序

此原型用于验证首版流程、信息层级和关键交互。它不是微信小程序实现代码。

建议验证路径

  1. 选菜：搜索菜名或食材，点击菜品。
  2. 点菜：勾选食材，确认日期、餐次和备注。
  3. 记录：完成或取消点菜，点击底部圆形按钮分享给家人。
  4. 购物：查看合并食材，勾选购入，手工添加。
  5. 管理：邀请成员、管理菜品、调整人数上限、修改家庭名称。
当前演示身份：妈妈（创建者）。因此同时显示管理入口和普通成员入口。点击手机外灰色区域不会触发手机内操作。
