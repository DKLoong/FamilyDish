# 家肴匣 · FamilyDish

一个面向家庭的小程序：多名成员共享菜品库、点菜记录与购物清单，谁点了菜、还缺哪些食材，一眼看清。

基于微信云开发，零服务器、零运维。不同家庭的数据自动隔离。

> 本仓库由上游 [PairBite](https://github.com/630999Steven/PairBite)（作者 **630999Steven**，[CC BY-NC-SA 4.0](LICENSE)）改造而来。小程序对外名称：**家肴匣**。

**当前状态**：M0–M7 已全部实现，代码即本文描述的能力，处于上线准备阶段。设计基线见 [`docs/ui/design-spec.html`](docs/ui/design-spec.html)（v1.6），需求与实施方案见 `docs/` 目录。

## 功能概览

- **家庭管理**：创建或加入家庭、家庭名称、家庭内昵称、3 天有效邀请码、人数上限 10–50、创建者／管理员／普通成员三级角色、退出／移除／解散。
- **共享菜品库**：创建者与管理员录入，结构化食材（`name / quantity / unit / note`）、步骤与计时器、分类、归档与恢复、5 道自行整理的示例菜。
- **显式点菜**：进入菜谱详情不产生记录；点击「我要点这道菜」并确认后才生成。一条记录只含一道菜，状态为待做／已完成／已取消。点菜时保存菜品与点菜人昵称快照。
- **家庭记录**：状态筛选、完成与取消需二次确认、历史快照只读、终态不可变更。
- **购物清单**：按点菜记录独立存放食材来源、页面合并显示；整组标记已购买、手工添加、删除权限控制；取消点菜只移除该订单带入的食材。
- **随机选菜与搜索**：同时匹配菜名与食材名，菜名命中的排在前面。
- **关于页**：版本号、版权与开源署名，版本号取自微信注入的线上版本，开发版回落到本地常量。
- **分享**：两条独立路径——邀请家人（带邀请码，落绑定页）与推荐给朋友（落首页）。点菜成功只提示「已点菜」。

**首版不做订阅消息**（无模板、无额度账本）、**不做长截屏分享**、**不做多人协作编辑**。二期计划：公共菜谱库、第三方菜谱导入、多家庭切换、实时监听。

上游基线界面截图保留在 `docs/images/` 下，展示的是改造前的绿色主题双人界面，**不代表当前界面**。当前 UI 以 `docs/ui/design-spec.html` 为准，可点击原型为 `docs/ui/index.html`。

## 技术栈

| 层 | 技术 | 说明 |
|---|------|------|
| 前端 | 微信小程序原生 | WXML + WXSS + JS，无第三方 UI 库 |
| UI | 自定义 WXSS + 暖木厨房设计令牌 | 主色 `#C9663B`，与上游绿色主题完全不同 |
| 后端 | 微信云函数 | Node.js + `wx-server-sdk ~2.6.3` |
| 数据库 | 微信云数据库 | NoSQL 文档数据库，7 个集合 |
| 存储 | 微信云存储 | 菜品图片，免费版经临时链接展示 |
| 通知 | 微信原生分享 | 首版不做订阅消息 |

无任何第三方 API 依赖，完全运行在微信云开发生态内。

| 页面 | 作用 |

**读写通道**：前端不调用 `wx.cloud.database()`。列表读取、详情读取与全部写操作都经 `wx.cloud.callFunction` 走 `familyApi`；7 个集合权限统一设为「仅管理端可读写」，不保留客户端直连旁路。

## 部署指南

### 前置条件

- 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 注册一个微信小程序账号，并在后台完成【小程序信息】与【小程序类目】。类目直接决定搜索匹配，请选与服务内容最贴近的类目，不要停在泛类目
- **须为公众平台正式注册的小程序 AppID**。开发者工具里的「测试号」不支持云开发

> 下方截图来自上游部署流程，展示的是微信开发者工具界面，可能随工具版本变化。

```bash

cd FamilyDish
```

用微信开发者工具**导入项目**，目录选仓库根目录（含 `project.config.json` 的一层）。**不要选 `miniprogram/` 子目录**：`miniprogramRoot` 与 `cloudfunctionRoot` 都相对根目录解析，选错会导致云函数目录找不到。

2. 用微信开发者工具打开项目

   ![image-20260426184308726](docs/images/image-20260426184308726.png)

3. 点击工具栏「云开发」按钮（不同版本位置略有不同）

   ![image-20260426184749860](docs/images/image-20260426184749860.png)

4. 按提示开通云开发环境（免费基础版即可）

### 第五步：上传云函数

在微信开发者工具中，**只部署这 3 个云函数**（对目录右键 →「上传并部署：云端安装依赖」）：

| 云函数 | 功能 |
|--------|------|
| `familyApi` | 统一读写入口：白名单 CRUD、领域动作、鉴权、事务、幂等 |
| `ensureUser` | 首次进入创建 `User`，返回家庭上下文 |
| `getFileURL` | `cloud://` 转临时链接 |

> **安全提醒**：`cloudfunctions/` 下仍有 9 个上游遗留目录（`getCoupleData`、`updateCoupleData`、`manageCategory`、`bindPartner`、`unbindPartner`、`updateKitchenName`、`sendNotify`、`getOpenId`、`createUser`）。前端已无任何调用，**切勿部署**——其中 `getCoupleData` / `updateCoupleData` 允许调用方传任意集合名与字段且无角色鉴权。若云端曾部署过，请在云开发控制台删除。

### 第六步：无需配置订阅消息

**首版不做订阅消息**。不需要申请模板、不需要字段 DATA ID、不需要配置模板环境变量。

> 公众平台里的「消息推送配置」（要填 URL / Token / EncodingAESKey）是客服消息回调，与订阅消息是两回事，本项目也不需要，保持关闭即可。

### 第七步：邀请体验成员

小程序未正式上线前，其他用户需被添加为**体验成员**才能访问：

1. [微信公众平台](https://mp.weixin.qq.com/) → 管理 → 成员管理 → 体验成员
2. 点击「添加」，输入对方微信号
3. 对方在微信中确认后，扫描体验版二维码即可使用

> 个人号最多可添加 15 名体验成员。不同家庭的数据通过 `familyId` + `UserFamily` 隔离，互不干扰。

### 第八步：上传代码

1. 点击微信开发者工具右上角「上传」，上传为体验版
2. 管理 → 版本管理里选为体验版，扫码即可进入（上一步被添加为成员的人才能扫码）
3. 正式上线前需提交审核；审核通过后在小程序后台「发布」

### 第九步：搜索收录（可选）

若希望小程序能被微信搜到：

## 使用流程

1. **创建者**打开小程序 → 填写家庭名称（1–12 字）与家庭内昵称（1–20 字）→ 创建家庭。
2. 在「我的」生成邀请码（6 位字母数字，3 天有效，可多人使用）→ 转发给家人。
3. **家人**输入邀请码、填写昵称加入 → 共享同一份菜品库、记录与购物清单。
4. 首页选菜 → 菜谱详情勾选已准备食材 → 点「我要点这道菜」→ 在底部弹层确认（用餐日期／餐次／备注均选填）→ 生成待做记录，未勾选的食材进入购物清单。
5. 记录页完成或取消点菜需二次确认；页面右下圆形按钮用于把小程序推荐给朋友。
6. 「我的 → 关于」查看版本与开源署名；退出／解散家庭在「家庭成员」页底部。

## 数据库说明

| 集合 | 用途 | 隔离 / 写入 |
|------|------|---------|
| `User` | 用户身份存根，`_id = openid` | `ensureUser` |
| `Family` | 家庭主体、状态、人数上限、邀请码 | 领域动作 |
| `UserFamily` | 权威成员关系、角色、家庭内昵称 | 领域动作 |
| `DishList` | 菜品与菜谱 | `familyId`，白名单 CRUD |
| `Category` | 菜品分类 | `familyId`，白名单 CRUD |
| `OrderList` | 点菜记录与菜品快照 | `familyId`，仅领域动作 |
| `ShoppingItem` | 购物来源记录 | `familyId`，白名单 CRUD + 领域动作 |

云函数用 `cloud.getWXContext()` 取 `openid`，查 `UserFamily` 得有效 `familyId` 与 `role`，再按动作查权限表。`familyId`、点菜人、角色、时间戳、状态变更一律由服务端写入；`Family.memberOpenids` 仅供展示，不得作为鉴权依据。

## 常见问题

**Q：必须多人才能用吗？**
A：不需要。单人可创建家庭并完整使用菜品、点菜与购物清单功能。

**Q：如何退出家庭或解散家庭？**
A：进入「我的 → 家庭成员」，页面底部按钮即可。普通成员与管理员为「退出家庭」，创建者为「解散家庭」（需二次确认）。退出、被移除或解散后只失去后续访问权限，历史点菜记录保留。

**Q：家人看不到我上传的图片？**
A：免费套餐下云存储权限无法改为「所有用户可读」，项目通过 `getFileURL` 云函数把 `cloud://` 文件 ID 转为临时链接实现互看。临时链接有效期约 2 小时（前端缓存 1.5 小时），长时间停留页面不刷新可能出现图片失效，刷新即可恢复。

**Q：点菜后家人会收到微信通知吗？**
A：不会。首版不做订阅消息，需要通知时用记录页按钮把小程序推荐给对方。

**Q：为什么返回上一页时内容会等一会儿才出现？**
A：这是微信客户端在页面返回时重建 webview 首帧的行为，原生导航栏先就绪、页面内容稍后绘制。已做过对照实验（停用返回时的数据刷新仍复现），不是代码问题。

**Q：云函数部署报错怎么办？**
A：先在云函数目录下执行 `npm install`，再上传部署。若仍报错，检查 Node.js 版本与 `wx-server-sdk` 版本是否匹配。
